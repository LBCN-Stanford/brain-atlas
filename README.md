# Intracranial Stimulation Atlas (deployed build)

The built site served at https://lbcn-stanford.github.io/brain-atlas/. This repository holds the static build only; the source is
developed by the LBCN, Parvizi Lab, Stanford University.

All data in this build are synthetic demonstration data. It contains no patient data.
